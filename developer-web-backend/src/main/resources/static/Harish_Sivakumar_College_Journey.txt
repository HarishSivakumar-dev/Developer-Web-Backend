CAPSTONE PROJECTS
================================================================
Tick-It (GitHub: HarishSivakumar-dev/Tick-It) - 350+ commits
Jira-like enterprise ticketing/grievance platform built as microservices:
Auth, Users, Projects, Tickets (+planned Notifications/Comments/Chat).
Uses Eureka, Spring Cloud Config Server, API Gateway, OpenFeign. Security
via Spring Security, JWT (with identity derived from auth context, not
client-supplied IDs), Google OAuth2, Redis-based sessions/logout/
blacklist. Redis caching for profiles/projects/tickets; atomic Redis
ZSET + Lua rate limiting (~10 req/min on auth). Kafka and WebSockets/
STOMP planned for notifications and real-time chat. Deployed with
Docker/Docker Compose.
 
SkillSprint (GitHub: HarishSivakumar-dev/SkillSprint) - Monolithic
Architecture Platform
Enterprise corporate learning/certification platform (not blockchain-
based), built as a monolithic architecture. 32 tables, 5 roles (USER ->
SUPER_ADMIN), Redis caching, rate limiting, schedulers, MySQL, Docker
(image v3->v4). Nginx used as a reverse proxy in front of the
application and for SSL/TLS termination (HTTPS). Backend complete.
